## 한 줄로 말하면

브라우저 확장 프로그램. 보고 있는 웹페이지를 마크다운 노트로 저장한다. AI 요약 템플릿을 붙일 수 있다.

## 왜 필요한가

스크랩만 하고 다시 안 읽는 인박스가 대부분의 병목이다.

**수집하는 시점에 이미 1차 가공된 카드**로 들어오면 재활용률이 달라진다. 광고와 메뉴가 걷힌 요약 카드는 나중에 열어볼 마음이 들지만, 원문 통째 저장은 열어볼 엄두가 안 난다.

## 설치와 세팅

1. Chrome/Edge 웹스토어 → **Obsidian Web Clipper** 설치
2. 확장 옵션 → 저장할 볼트 선택 → 저장 폴더 `00.수집`
3. Template 추가 → 속성으로 `source`, `clipped`, `tags` 지정
4. (선택) Interpreter에 Claude 또는 OpenAI API 키 입력 → 프롬프트 예시

```
이 글의 핵심 주장 3개와 실무 적용 포인트 1개를 뽑아줘
```

## 라이브 시연

1. 아무 기사나 열고 클리퍼 아이콘 클릭 → 미리보기 확인 → 저장
2. 옵시디언으로 전환 → `00.수집`에 노트가 이미 들어와 있다
3. AI 템플릿을 켠 상태로 한 번 더 클리핑 → **광고·메뉴가 걷힌 요약 카드**로 저장된다
4. 그 노트에서 `Ctrl+S` → 6회차의 Linter가 서식까지 정리한다

여기서 한 마디. "수집이 곧 정리입니다. 따로 정리하는 단계가 없어졌습니다."

## 직접 해보기 (5분)

1. 확장 프로그램을 설치한다
2. 관심 있는 기사를 하나 클리핑한다
3. `00.수집`에서 그 노트를 열고 1회차에서 만든 노트를 `[[ ]]`로 링크한다

## 흔한 함정

> [!warning] 로그인이 필요한 사내 시스템과 PDF 뷰어는 제대로 안 긁힌다
> 확장이 읽는 건 브라우저에 렌더된 HTML이다. 뷰어 안에 들어 있는 내용은 잡히지 않는다.

> [!warning] API 키는 브라우저에 저장된다
> **회사 공용 PC에서는 넣지 말 것.** 개인 계정 요금이 남에게 쓰인다.

> [!warning] 전문 통째 저장은 저작권 문제가 된다
> 사내 공유까지 갈 자료라면 요약 + 출처 링크를 원칙으로 한다.
