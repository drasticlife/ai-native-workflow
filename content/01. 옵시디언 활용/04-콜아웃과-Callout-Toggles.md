## 한 줄로 말하면

텍스트를 색깔 박스로 감싸 강조한다. 단축키 한 번으로 변환된다.

## 왜 필요한가

나중의 내가 훑을 수 있어야 다시 읽는다. **핵심·주의·질문이 눈에 안 띄면 그 노트는 죽은 노트다.**

자동화 3층 구조 중 맨 위층 — 시각화에 해당한다. 아래 두 층(서식 정리, 템플릿)은 6·7회차에서 다룬다.

## 설치와 세팅

1. 콜아웃 문법 자체는 코어 기능이다
2. 커뮤니티 플러그인 → **Callout Toggles** 설치
3. 설정 → **단축키(Hotkeys)** → 자주 쓸 다섯 종에 키를 매핑한다

| 타입 | 용도 | 추천 키 |
|---|---|---|
| `[!note]` | 요약·일반 참고 | `Alt+1` |
| `[!tip]` | 팁·노하우 | `Alt+2` |
| `[!warning]` | 주의·실수 방지 | `Alt+3` |
| `[!question]` | 미해결 질문 | `Alt+4` |
| `[!quote]` | 인용·핵심 문장 | `Alt+5` |

표에 없는 타입도 있다 — `[!info]`(정보), `[!success]`(성공), `[!bug]`(버그) 등. 다섯 개로 시작해서 정말 필요할 때만 늘린다. 종류를 늘리는 건 아래 "노트당 세 개 이내" 원칙과 반대 방향이라는 걸 기억한다.

## 라이브 시연

1. 손으로 직접 타이핑해 보여준다

```markdown
> [!warning] 마감 임박
> 금요일까지 초안 넘겨야 함
```

2. 그다음 문장을 드래그하고 `Alt+3` → **한 번에 박스로 변환된다.** 여기가 이 회차의 핵심 장면이다
3. 타입 뒤에 `-`를 붙이면 접히는 박스가 된다 — 긴 노트에서 상세 내용을 감출 때 쓴다. `+`를 붙이면 펼친 상태를 명시한다(기본값과 같지만, 나중에 `-`로 접었다가 되돌릴 때 명확하다)

```markdown
> [!note]- 상세 내용 (클릭하면 펼쳐짐)
> 평소엔 접혀 있다가 필요할 때만 연다
```

## 직접 해보기 (5분)

자기 노트에서 문장 세 개를 골라 각각 `tip` / `warning` / `question`으로 바꾼다. 손 타이핑 한 번, 나머지 둘은 단축키로 해보면 차이가 바로 느껴진다.

## 흔한 함정

> [!warning] 문법이 조금만 틀려도 안 먹는다
> `>` 뒤의 공백, 대괄호와 느낌표 순서(`[!타입]`)를 하나라도 틀리면 그냥 인용문으로 나온다. **그래서 단축키를 쓰는 것이다.**

> [!tip] 노트당 세 개 이내
> 콜아웃을 남발하면 전부 강조 = 강조 없음이 된다. 정말 눈에 걸려야 하는 것만 감싼다.
