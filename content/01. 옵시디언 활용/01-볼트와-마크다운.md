## 한 줄로 말하면

볼트(Vault) = 노트를 담는 그냥 폴더. 노트 = 그냥 텍스트 파일.

## 왜 필요한가

데이터가 내 손에 있어야 백업·AI 연동·다른 도구 연결이 전부 가능해진다. 이게 옵시디언을 쓰는 유일하고 가장 큰 이유다.

대부분의 노트앱은 글을 회사 서버에 가둔다. 서비스가 문을 닫으면 내보내기 기능에 의존해야 하고, 그마저 없으면 그대로 잃는다. 옵시디언은 내 PC 폴더에 `.md` 텍스트 파일로 저장한다. 프로그램을 지워도 파일은 남는다.

![[Pasted image 20260801203747.png]]
*내 폴더에 있으면 서비스가 없어져도 남는다*

## 설치와 세팅

1. `obsidian.md` 접속 → **Download** (Windows/Mac/iOS/Android 전부 무료)
2. 첫 실행 → **Create new vault** → 이름은 `내지식창고`, 위치는 동기화 폴더 안 (Google Drive / OneDrive / iCloud)
3. 설정(`Ctrl+,`) → **Editor** → `Default editing mode: Live Preview`
4. 폴더 4개 생성

```
00.수집      ← 일단 던져넣는 곳
01.정리      ← 다듬은 노트
02.프로젝트   ← 진행 중인 일
99.보관      ← 끝났지만 버리긴 아까운 것
```

![[Pasted image 20260801203856.png]]
*번호가 커질수록 오른쪽 — 수집에서 보관까지*

## 라이브 시연

1. 볼트 폴더를 **윈도우 탐색기로 열어** 보여준다 — "그냥 폴더죠?"
2. `.md` 파일을 **메모장으로 직접 열기** → 옵시디언을 켜면 그 내용이 그대로 보인다
3. 마크다운은 세 개만 보여준다

```markdown
# 제목
- 목록
**굵게**
```

세 개를 보여준 다음 한 마디 덧붙인다. "문법은 이게 전부입니다. 나머지는 필요할 때 찾으면 됩니다."

![[Pasted image 20260801203921.png]]

## 직접 해보기 (5분)

`00.수집` 폴더에 `내첫노트.md`를 만들고, 오늘 회의나 업무 내용을 5줄 쓴다.

> [!tip] 이 노트를 끝까지 쓴다
> 앞으로 나오는 아홉 개 기능이 전부 **이 노트 하나**에 붙는다. 예제를 갈아타지 않아야 "수집 → 정리 → 활용"이 한 흐름으로 몸에 남는다.

## 흔한 함정

> [!warning] 회사 보안 폴더·네트워크 드라이브에 볼트를 만들지 말 것
> 플러그인이 파일을 읽고 쓰는 속도가 느려지거나 아예 오작동한다. 로컬 경로에 두는 것을 권한다.

> [!warning] 클라우드 동기화 폴더는 편한 만큼 충돌이 난다
> 여러 기기에서 동시에 편집하면 `파일명 (충돌본).md` 같은 사본이 생긴다. 대응 방법은 10회차에서 다룬다.
