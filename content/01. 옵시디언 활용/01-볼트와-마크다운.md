## 한 줄로 말하면

볼트(Vault) = 노트를 담는 그냥 폴더. 노트 = 그냥 텍스트 파일.

## 왜 필요한가

데이터가 내 손에 있어야 백업·AI 연동·다른 도구 연결이 전부 가능해진다. 이게 옵시디언을 쓰는 유일하고 가장 큰 이유다.

대부분의 노트앱은 글을 회사 서버에 가둔다. 서비스가 문을 닫으면 내보내기 기능에 의존해야 하고, 그마저 없으면 그대로 잃는다. 옵시디언은 내 PC 폴더에 `.md` 텍스트 파일로 저장한다. 프로그램을 지워도 파일은 남는다.

노트 앱을 두세 번 갈아탄 사람이면 다 겪는 일이 있다. 예전 노트를 새 서비스로 옮기면 서식이 깨지거나, 아예 못 옮긴다. 원인은 하나다 — 내 글이 그 서비스 전용 형식에 갇혀 있었기 때문이다. 옵시디언은 애초에 가둘 게 없다. 텍스트 파일은 어떤 프로그램으로도 열리는 가장 낮은 공통분모다.

그래서 얻는 게 셋이다. 서비스가 사라져도 글은 남고, 백업 방식은 내가 정하고, AI 도구나 다른 편집기를 붙이는 데 제약이 없다. 폴더 안 텍스트 파일이라는 사실 하나가 이 셋을 전부 연다.

*내 폴더에 있으면 서비스가 없어져도 남는다*

## 설치와 세팅

1. `obsidian.md` 접속 → **Download** (Windows/Mac/iOS/Android 전부 무료)
2. 첫 실행 → **Create new vault** → 이름은 `내지식창고`, 위치는 동기화 폴더 안 (Google Drive / OneDrive / iCloud) 또는 로컬 PC
3. 설정(`Ctrl+,`) → **Editor** → `Default editing mode: Live Preview`
4. 폴더 4개 생성

```
00.수집      ← 일단 던져넣는 곳
01.WIKI      ← 지식을 축적하는 곳 (AI가 보는 폴더)
02.PARA      ← 제텔카스텐 원리에 따라 자료를 정리하는 곳 (사람이 보는 폴더)
99.SYSTEM    ← 옵시디언 관리 폴더(스키마, 첨부화일, 템플릿 등)
```

![[_attachments/fig-01-01-b.png]]
*하나의 수집함이 AI가 보는 곳과 사람이 정리하는 곳으로 갈라진다*

## 라이브 시연

1. 볼트 폴더를 **윈도우 탐색기로 열어** 보여준다 — "그냥 폴더죠?"
2. `.md` 파일을 **메모장으로 직접 열기** → 옵시디언을 켜면 그 내용이 그대로 보인다
3. 마크다운은 세 개만 보여준다

```markdown
# 제목
- 목록
**굵게**
```

세 개를 보여준 다음 한 마디 덧붙인다. "문법은 이게 전부입니다. 나머지는 필요할 때 찾으면 됩니다."

## 자주 쓰는 문법 더 보기

외울 필요 없다. 필요할 때 이 표만 다시 보면 된다.

| 기능     | 문법                                     | 결과                     |
| ------ | -------------------------------------- | ---------------------- |
| 제목     | `#` `##` `###` (기호 뒤 공백 필수)            | 크기순 제목                 |
| 강조     | `**굵게**` `*기울임*` `~~취소선~~` `==하이라이트==` | 굵게 · 기울임 · 취소선 · 하이라이트 |
| 체크리스트  | `- [ ] 할 일` / `- [x] 완료`               | 빈 체크박스 / 완료 표시         |
| 표      | `\| 항목 \| 값 \|`                        | 표                      |
| 이미지 크기 | `![[파일명\|300]]`                        | 너비 300px, 비율은 자동 유지    |

> [!tip] 표는 손으로 안 맞춘다
> 파이프(`|`) 위치를 맞추는 게 번거로우면 Advanced Tables 같은 플러그인이 자동 정렬해준다. 플러그인 도입은 6회차부터 순서대로 — 지금은 문법만 알아두면 충분하다.

링크 `[[ ]]`와 콜아웃 `[!tip]`은 각각 2회차·4회차에서 통째로 다룬다. 여기서는 문법만 존재를 알아두고 넘어간다.

> 서식은 AI에게 시키거나 Editing Toolbar 플러그인으로 처리한다. 그중 정말 자주 쓰는 것만 단축키로 지정한다.
