## 한 줄로 말하면

전체 노트 본문 검색. 한국어는 `Omnisearch` 플러그인이 오타와 어절까지 잡아낸다.

## 왜 필요한가

정리를 잘 하려고 애쓰는 대신 **잘 찾으면 된다.**

검색이 확실해지면 폴더 구조를 고민하는 시간이 통째로 사라진다. 어디에 넣었는지 몰라도 되니까 일단 넣는 것에 대한 심리적 저항도 같이 없어진다.

## 설치와 세팅

1. 코어 검색은 `Ctrl+Shift+F`로 바로 쓴다
2. 설정 → **커뮤니티 플러그인** → 안전 모드 끄기 → **Browse(탐색)** → `Omnisearch` 검색 → 설치 → 활성화
3. Omnisearch 설정에서 `Vault search` 단축키를 `Ctrl+O` 등 편한 키에 매핑

## 라이브 시연

1. `Ctrl+Shift+F`로 단어 검색 → 좌측에 매칭된 문장이 미리보기로 뜬다
2. 검색 연산자 세 개를 보여준다

```
path:프로젝트     특정 폴더 안에서만
tag:#회의         태그로 좁히기
file:2026-07      파일명으로 좁히기
```

3. **일부만 기억나는 단어**로 Omnisearch 검색 → 코어 검색이 못 찾는 것을 잡아낸다
4. `Ctrl+P` 명령 팔레트를 열며 — "옵시디언의 모든 기능은 여기서 이름으로 실행됩니다. 단축키를 못 외워도 됩니다."

## 직접 해보기 (5분)

1. 자기 노트에서 단어 하나를 검색한다
2. `path:` 연산자를 붙여 폴더를 한정해본다
3. `Ctrl+P`를 누르고 `Graph`를 입력해 그래프 뷰를 실행한다 — 단축키 없이 기능을 부르는 감을 잡는 게 목적이다

## 흔한 함정

> [!warning] Omnisearch는 첫 실행 때 전체 색인을 만든다
> 노트가 많으면 몇 분씩 걸리고 그동안 검색 결과가 비어 보인다. **강의 전에 미리 한 번 돌려둘 것.**
