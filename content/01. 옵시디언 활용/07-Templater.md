## 한 줄로 말하면

날짜·제목·커서 위치까지 계산되는 동적 템플릿이다.

## 왜 필요한가

회의록·주간보고·독서노트는 매번 같은 뼈대다. **뼈대 만드는 시간이 생각하는 시간을 잡아먹는다.**

6회차 Linter가 "이미 쓴 것을 정리"한다면, Templater는 "쓰기 전의 판을 깔아준다". 자동화 3층 구조의 2층에 해당한다.

## 설치와 세팅

1. 커뮤니티 플러그인 → **Templater** 설치
2. 설정 → `Template folder location`: `90.템플릿`
3. `Trigger Templater on new file creation` ON
4. 단축키 → `Templater: Open insert template modal` → `Alt+T`

## 라이브 시연

`90.템플릿/회의록.md`를 만들고 아래를 넣는다.

```markdown
---
type: meeting
created: 2026-08-01
---
## 2026-08-01 회의 — AI-3대장-비교와-Claude-Code-실전가이드

### 참석자
<% tp.file.cursor(1) %>

### 논의
### 결정사항
### 액션 아이템
- [ ]
```

1. 새 노트를 만든다 → `Alt+T` → `회의록` 선택
2. **날짜가 자동으로 박히고, 커서가 참석자 칸에 가 있다**
3. 한 마디 덧붙인다 — "이걸 매일 하면 1년에 며칠 아낍니까?"

## 직접 해보기 (5분)

1. `90.템플릿/일일업무.md`를 만든다
2. 위 코드를 복사해 붙인다
3. 새 노트에서 `Alt+T`로 삽입해본다

## 흔한 함정

> [!warning] 템플릿 폴더를 지정하지 않으면 목록이 안 뜬다
> `Alt+T`를 눌렀는데 빈 창이 나오는 경우의 1순위 원인이다. 설정에서 `Template folder location`을 먼저 확인한다.

> [!warning] 코어 플러그인 `Templates`와 Templater는 다른 것이다
> 이름이 비슷하지만 코어 쪽은 정적 치환만 한다. 날짜 계산·커서 이동은 **Templater**에만 있다.

> [!warning] 템플릿 문법을 "설명하는 문서"를 새로 만들 때 코드가 실행된다
> `Trigger Templater on new file creation`이 켜져 있으면, 예제 코드가 적힌 문서를 새로 만드는 순간 그 코드가 **진짜로 실행돼** 날짜로 치환된다. 이 강의안을 만들면서 실제로 당했다. 설명 문서는 템플릿 폴더 밖에서, 빈 파일을 먼저 만든 뒤 내용을 붙여넣는 방식으로 작성한다.

> [!tip] 만든 직후 한 번 테스트할 것
> `와 ` 사이는 자바스크립트다. 오타가 나면 에러를 띄우지 않고 **조용히 빈칸으로 나온다.** 몇 주 뒤에 발견하면 그동안 쓴 노트가 전부 비어 있다.
